# tic-tac-toe

tic-tac-toe in one single html file. no libs, no assets.

play against an unbeatable cpu or a friend on the same screen.

## play

open `index.html` in any browser. that's it.

## controls

| key | does |
|---|---|
| click / tap | place mark |
| 1-9 | place mark |
| r | restart round |
| m | mute |

## stuff inside

- minimax cpu, good luck beating it
- 1P and 2P modes
- scoreboard saved in the browser, RESET SCORE wipes it
- clicks made with webaudio, zero audio files
